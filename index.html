1. 개요

본 앱은 OCR(광학 문자 인식) 및 AI 분류 알고리즘을 활용하여 학생들의 오답노트 작성 시간을 대폭 단축시키고 취약 단원 위주의 플래너를 자동 생성해주는 시스템입니다.

2. 주요 기능 및 사용 순서

  1. 학습자 환경 설정: 상단의 초/중/고 선택 탭을 클릭하여 본인의 학년급에 맞는 과목을 지정합니다.
  2. 스캔 및 라벨링: 오답 스캐너에서 샘플 문제를 선택하고 [AI 문제 스캔] 버튼을 눌러 라벨링 결과를 확인합니다.
  3. DB 저장: 분류된 결과를 오답 데이터베이스에 등록합니다.
  4. 통계 및 플래너 활용: 취약 단원 도넛 차트를 통해 약점을 파악하고 일일 추천 학습 항목을 완료합니다.

인공지능과 미래사회 수행평가 정보

성취기준:

[12인기03-04] 분류 모델의 개념을 이해하고, 실생활 문제 해결을 위한 인공지능 프로그램을 설계한다.

수행평가 5대 요소 반영 내역:

1. 실생활 문제: 오답노트 정리 시간 단축 및 효율적 공부 계획 수립

2. AI 단계적 과정: 이미지 수집 → OCR 텍스트 전처리 → ML 단원 분류 → 데이터 분석

3. 프로그램 작성 계획서: GitHub Pages 배포 및 Google Apps Script 백엔드 연동 설계

4. 사용자 매뉴얼: UI 내 4단계 가이드 및 상세 모달 제공

5. 발표 근거: 성취기준 명시 및 작동 시연이 가능한 웹 앱 형태 배포
